# Security policy

CWE Witness runs C programs supplied by its user. The runner applies resource limits and uses Linux isolation for selected observers, but it is intended for trusted research samples and does not guarantee containment of actively malicious code. Use a disposable VM for untrusted samples.

Please report a vulnerability privately through the Security tab of the repository from which you obtained this release, using its private vulnerability reporting option when enabled. If that option is unavailable, contact the maintainers through GitHub before sharing details publicly. Include the affected version, a concise impact description, and safe reproduction steps. Do not include real credentials or private data in a public issue.
